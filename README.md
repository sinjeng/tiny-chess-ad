A compact chess engine in a single 4 KB Python file: negamax alpha-beta search with iterative deepening to a fixed node budget, quiescence search, a transposition table, and piece-square-table evaluation, playing the make.fun tiny-chess-01 gauntlet over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18100 python3 main.py
```
